The Computon Model

A universal framework to formally reason about compositional high-level computations via categorical semantics.

What is a computon?

It is the fundamental unit of composition, which defines a high-level computation driven by control. Intuitively, it is a bipartite graph where nodes are typed ports or computation units. A unit is a collection of computing devices each receiving at least one input and producing exactly one output. Edges simply represent either control flow or data flow. There are three major classes:

  • Trivial computons (only possess ports)
  • Primitive computons (all ports are attached to exactly one unit)
  • Composite computons

Colimit-Semantics of Control-Based Composition

Composing computons into more complex ones is done through algebraic operators characterised as finite colimit constructions in the category of computons. There are operators to form:

  • Total/partial sequential computons
  • Asynchronous/synchronous parallel computons
  • Open/closed branching computons (cf. non-deterministic choice)
  • Head-iterative computons (cf. while)
  • Tail-iterative computons (cf. do-while)

Key computon properties

  • Explicit separation of control flow and data flow
  • Separation of composition from operational semantics
  • Control-driven computation
  • Structural correctness-by-construction

Why Computons?

Classical models of computation like Turing machines a suitable to describe one computation at a time (i.e., a single algorithm). But they don't adequately capture interactions among multiple computing devices.

Computation = Interacting Computing Devices

Instead of a single machine, computation is built from multiple interacting computons to activate their "units" in some order.

Modularity by black-boxing

Computons are modular black boxes. What matters is how they interact, not their internals.

Control/Data Flow

Control flow defines the order of execution of computons, whilst data flow specifies how data is exchanged among them.

Control flow is always present in any composite, i.e., in any high-level computation. Data flow is optional.

Compositionality

Colimit-based composition is a mechanism to inductively combine computons into more complex ones.
